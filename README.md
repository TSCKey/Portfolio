# Omar Abulebda — Software Engineer

A modern, responsive, and animated personal portfolio website built with HTML, CSS, and JavaScript.

## ✨ Features

- **Modern Dark/Light Theme** with smooth transition
- **Custom Cursor** with interactive hover effects
- **Smooth Scrolling** using Lenis
- **GSAP Animations** + ScrollTrigger
- **Fully Responsive** design
- **Project Filter System**
- **3D Tilt Effect** on project cards
- **Working Contact Form** (powered by EmailJS)
- **Mobile-friendly** navigation

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Animations**: GSAP + ScrollTrigger
- **Smooth Scroll**: Lenis
- **Form Handling**: EmailJS
- **Fonts**: Inter + Space Grotesk (Google Fonts)
